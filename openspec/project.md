# Keppri-Gym

## Stack

- **React Native**
- **Expo**
- **TypeScript**
- **Jest**
- No backend (Mock data Only)
- Local in-memory state

## Architecture

```
src/
├── components/
├── screens/
├── domain/
├── data/
└── types/
```

> Business rules must remain independent from React Native UI.

## Commands

### Run application

```bash
npm run ios
npm run android
```

### Run tests

```bash
npm test
```
