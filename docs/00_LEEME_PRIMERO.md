## Por qué recibes esto

En KEPPRI no tenemos "empleados que usan IA". Tenemos **espartanos**: personas que combinan criterio propio, conocimiento técnico, un método de trabajo riguroso e inteligencia artificial para rendir como lo haría un equipo completo.

Esta prueba no busca saber cuánto sabes hoy. Busca ver **qué tan preparado estás para convertirte en espartano**: cómo aprendes algo nuevo, cómo diriges a la IA sin perder el control técnico y cómo sigues un método de principio a fin, desde el insumo funcional hasta una app lista para publicar.

## Antes de empezar el cronómetro (parte de tus 30 min de preparación)

Deja listo tu entorno para no gastar tiempo de la prueba en instalaciones:

```bash
node -v                                  # Node.js 20 o superior
npm install -g @fission-ai/openspec@latest
npx create-expo-app@latest --help        # verifica que Expo funciona
```

Y ten a mano tu asistente de IA de código configurado (Claude Code, Cursor, Copilot, Windsurf, etc.) y Expo Go en tu celular o un emulador.

## Reglas del juego

1. **Debes usar IA.** Es obligatorio. Queremos ver cómo la diriges, no que la escondas.
2. **Debes usar OpenSpec** para correr el ciclo completo: propuesta, specs, diseño, tareas, implementación y archivo.
3. **Registra tu uso de IA** en la bitácora (`plantillas/bitacora_ia.md`). Nos interesa especialmente lo que la IA hizo mal y cómo lo detectaste.
4. **La prueba es corta a propósito.** Prioriza **recorrer todo el ciclo** sobre pulir la interfaz. Una app fea que cumple la spec, tiene pruebas y está lista para publicar vale más que una bonita a medias.
5. Si algo del insumo es ambiguo, **decide tú, anota el supuesto y sigue**.
